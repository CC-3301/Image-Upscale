## 报告（维护者 2026-09-18，v0.2.5）

`realcugan-pro` 出图「效果还不如原图」：漫画网点（screentone）被抹平、画面发"喷枪糊"。

## 定位（参考 `references/088.webp`，命令 `--width 1600`）

1. **模型侧没问题**：临时去掉清单里的 `pro yes` 复现修复前输出 —— 网点区局部高频只有 `11.27`，工单 40 修复后 `28.45`（归一化本身把网点救回 2.5 倍）。官方同参数 `-c 2` 的统计恰好等于"修复前"，`-c 1` 对齐"修复后"。
2. **JPEG 不是原因**：PNG 28.45 → JPEG q90 30.06。
3. **缩小这一步是主因**：`--width 1600` 把模型 2x 输出（2092 宽）缩到 1600（0.765 倍），而当时的 `resize_rgb` 用 stb 简易 API `stbir_resize_uint8_linear`，其**缩小**默认滤镜是 `STBIR_DEFAULT_FILTER_DOWNSAMPLE = MITCHELL`（stb 里最软的一种；同一函数"放大"用的却是 Catmull-Rom —— 原注释只写"Catmull-Rom"，掩盖了这个不对称）。
4. **残留差距有一半是物理必然**：网点在 2x 下周期约 2 像素，缩到 1600 后 1.53 像素、越过输出图可表示上限，任何重采样只能低通掉（无摩尔纹）或产生摩尔纹（看着更清晰但是假的）。

## 定案（维护者选择）

不做"替一个默认滤镜"，而是**做成可选**：

| 界面 | 引擎 token | 内核 |
|---|---|---|
| Lanczos（默认） | `lanczos` | 自定义 Lanczos-3（`sinc(x)·sinc(x/3)`，stb 无内置，走 `STBIR_FILTER_OTHER` 回调） |
| Catmull-Rom | `catmullrom` | stb `CATMULLROM` |
| Bicubic | `bicubic` | stb `MITCHELL`（Mitchell-Netravali；三次卷积家族里最常被叫 bicubic 的那个） |
| Box | `box` | stb `BOX`（面积平均；整数倍缩小等同盒式） |

命名口径由维护者定案：界面 Bicubic 的核是 Mitchell，Catmull-Rom 单独一项；Area 与 Box 在 stb 里同核，合并为一项 `Box`；原 B-spline（最柔）去掉。

作用范围：**只在缩小路径**（输出宽高都小于源）——目标尺寸小于模型原生输出的那一步、直通缩放、及其 alpha 同步缩放；**放大一律 Catmull-Rom**。这里与 waifu2x-caffe 有本质差异：它的 `waifu2x.cpp` 是 `scaleNum = ceil(log2(目标))` 循环跑 2x 模型、收尾 `ShrinkImage` **永远是缩小**（INTER_CUBIC，<0.5 倍换 INTER_AREA），所以它不需要放大滤镜；本项目 spec 明确“多轮迭代放大不做”，单次原生倍率后目标超过原生倍率时最后一步就是插值放大。选项**不入输出文件名**（维护者定案）。
