# 06: AUTO 降噪

**Parent:** .scratch/image-upscale/spec.md

**What to build:** 用户选择降噪档位 AUTO 时，引擎在推理前对输入做伪影启发式估计（JPEG 块效应 + 高频残差），映射到规范档位（无/低/中/高），再经当前模型的映射表落到专属参数。用户手动选档后 AUTO 无痕退出；估计器不知道任何模型的存在。

**Blocked by:** 03

**Status:** done（自动化验收全绿）

- [x] 降噪参数接受 AUTO；估计输出规范档位并经模型映射执行
- [x] 选档结果在 verbose 输出中可观测（规范档位 + 模型侧落点），供测试断言
- [x] 合成测试图（干净 / 轻度 JPEG 伪影 / 重度伪影）分别映射到合理档位
- [x] 不支持降噪的模型收到 AUTO 时明确报错，与手动档行为一致
- [x] 手动档行为完全不受影响
