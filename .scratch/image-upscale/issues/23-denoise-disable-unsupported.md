# 23: 不支持降噪的模型降噪控件未灰置，仍可选"自动"导致报错

**Parent:** .scratch/image-upscale/spec.md

**Category:** bug

**Status:** done（随 v0.2.1 发布：https://github.com/CC-3301/Image-Upscale/releases/tag/v0.2.1）

> *This was generated by AI during triage.*

## 报告（2026-09-14 人工测试）

不支持降噪的模型会自动选"无"，但仍然可以选回"自动"，这样会报错；不支持降噪的模型，降噪选项应该直接灰掉不让选择。

## Triage 验证记录（代码确认，报错链路完整）

- `models/manifest.conf`：digital-art-4x 仅有 `denoise none digital-art-4x` 一档（映射表无 低/中/高）
- GUI `OnModelChanged`：`DenoiseBox.IsEnabled = m.Denoise.Count > 1 || m.Denoise.ContainsKey(0)` → digital-art-4x 的 `ContainsKey(0) == true` → **控件仍启用**，可选项为 自动/无
- 选"自动" → GUI 发 `--denoise auto` → 引擎 `main.cpp`："does not support denoise (cannot use AUTO)" → EXIT_PARAM → GUI 弹"失败：参数错误"

**判据缺陷**："支持降噪"应是存在 none 以外的档位（低/中/高任一），而非包含 none。工单 08 验收单写了"数字艺术模型 → 降噪灰置"，实现与验收不符，属回归/漏项。

## 分诊建议

推荐 `ready-for-agent`：

- 判据改为 `m.Denoise.Keys.Any(k => k != 0)`；不支持 → `DenoiseBox.IsEnabled = false` + 固定"无" + 旁边灰字提示（如"该模型不支持降噪"），与 CLI 行为一致
- 回归：digital-art-4x 选中时控件灰置；realesr-general-x4v3（有低/中/高）正常可选
