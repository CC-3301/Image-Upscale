## Triage 结论（不删）

**manifest.conf 是模型清单（工单 03 引入），引擎与 GUI 共用的唯一模型元数据源**：

- 每个 `model` 块声明：模型 id / 显示名 / 图像类型分组 / 架构（waifu2x | cugan | rrdb | compact）/ 权重目录 / 原生倍率档 / 对应 scale 的 prepad / 网络 blob 输入输出名 / tile 自动分档策略
- **降噪映射**：规范档位（无/低/中/高）→ 各架构专属变体 token（如 waifu2x 的 `noise1_scale2.0x_model`、Real-CUGAN 的 `denoise3x`、realesr-general 的 `-low/-mid/-high` 权重后缀），"支持降噪 = 存在 none 以外档位"的能力判据也来自这里（工单 23）
- **用户自导模型入口**：第三方 ncnn 模型放进 models/ 加一段清单即可用（spec 用户故事 4，如 MangaScaleV3）

删除它 = 把 7 个模型的全部元数据硬编码进引擎与 GUI 源码，且自导模型入口消失。两侧各有解析器（`engine/src/main.cpp` 的 `parse_manifest`、GUI 的 `EngineClient.ParseManifest`），文件为人可读 ini 风格文本。

**处置：保留不动（wontfix）。** 同类知识库写入不适用（文件不是"被拒绝的请求"，而是已建成组件）。
