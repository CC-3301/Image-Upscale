# 01: 引擎端到端超分链路（首个模型 + 倍率模式）

**Parent:** .scratch/image-upscale/spec.md

**What to build:** 用户在命令行对一张图片执行倍率模式超分：调用引擎 exe，得到按命名规则输出的放大图。本工单打通最高风险的地基——构建系统与 ncnn 集成（Vulkan + CPU 双后端）、图像编解码（JPG/PNG/WebP + 质量 0-100）、输出命名（倍率段 `2.0x`）、同名覆盖、语义化退出码，并建立本项目的唯一测试缝（引擎 CLI 进程边界）。

**Blocked by:** None (can start immediately)

**Status:** done（自动化验收全绿）

- [ ] 以首个打包漫画模型对单张 .png/.jpg/.jpeg/.webp 输入完成 2x 超分，产物命名为 `A-(模型名)-2.0x`（文件夹输入）或同目录 `A-(模型名)-2.0x.<输出后缀>`（单文件输入）；模型名段用括号包裹
- [ ] 输出格式 JPG（默认，质量默认 90）/PNG/WebP 可选，不跟随输入格式
- [ ] Vulkan 设备可用时走 GPU；不可用或显式指定时回退 CPU，产物均可正常解码
- [ ] 输出同名文件直接覆盖
- [ ] 退出码语义化：成功 / 参数错误 / 推理失败 / IO 错误各不相同，报错写入 stderr
- [ ] 测试缝测试就位：确定性断言（命名、格式、尺寸、覆盖、退出码）+ 64px 级小图固定 CPU 后端的 PSNR 容差断言，全部经真实进程调用引擎
