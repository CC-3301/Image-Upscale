# 07: GUI 骨架（单图端到端）

**Parent:** .scratch/image-upscale/spec.md

**What to build:** 用户第一次打开 GUI：拖入或选择一张图片，选择模型、尺寸模式（倍率/宽/高三选一单选）、降噪档位、输出格式与质量，点开始后看到进度，结束后得到与 CLI 完全同款的产物。GUI 只是引擎缝的另一个调用方（进程调用），不承担任何推理职责。界面仅中文。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 拖拽/文件选择单张图片，参数面板（模型分组列表、尺寸模式单选、降噪、格式、质量）可用
- [ ] 进程调用引擎，行式进度被解析并展示；失败展示退出码与错误信息
- [ ] 产物命名与 CLI 完全一致
- [ ] 界面全部中文，无英文残留
- [ ] GUI 不设自动化测试，手动验收清单通过（写入工单评论）
