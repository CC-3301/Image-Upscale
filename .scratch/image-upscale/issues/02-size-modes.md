# 02: 完整尺寸模式（目标尺寸 + 直通缩放）

**Parent:** .scratch/image-upscale/spec.md

**What to build:** 用户可以指定目标尺寸（只给目标宽或目标高二选一）而不只是倍率：目标大于原图时，引擎做一次原生超分再精确 resize 到目标；目标小于原图时直通缩放——完全跳过模型推理、等比缩放直达目标（不裁掉画面），产物命名中模型位置写 `Resize`。与 waifu2x-caffe 的行为习惯一致。

**Blocked by:** 01

**Status:** done（自动化验收全绿）

- [x] 目标宽度/目标高度参数互斥：同时指定时报参数错误并使用对应退出码
- [x] 目标 ≥ 原图：选取"原生倍率 ≥ 目标/原图"的最小档做一次超分，再精确 resize（含宽高比推算的另一维度）到目标
- [x] 目标 < 原图：直通缩放，不加载/运行任何模型，命名形如 `A-(Resize)-1920x`
- [x] 命名只写用户指定的维度：宽 → `1920x`，高 → `1080x`（x 均在数字后）
- [x] 倍率模式行为不受影响（永远超分，无直通判断）
- [x] 直通缩放为高质量重采样，输出格式与质量参数照常生效
