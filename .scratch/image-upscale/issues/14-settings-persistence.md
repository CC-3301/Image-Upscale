### Agent Brief（2026-09-14 grilling 定稿，推进 ready-for-agent）

**Category:** enhancement
**Summary:** GUI 记忆核心处理设置至 exe 同目录 `setting.ini`，行为对齐 waifu2x-caffe（存储位置、写入时机、范围）

**Current behavior:**
无任何持久化：每次启动全部回到硬编码默认（默认模型、倍率模式、JPG、质量 90）；用户每次打开软件都要重设。

**Desired behavior:**
- **存储**：exe 同目录 `setting.ini`（Windows ini 文本格式，与 waifu2x-caffe 同构；文件不存在即首次运行，全部默认；写失败如目录只读则静默放弃，不崩溃不弹窗）
- **恢复**（启动时）：模型、尺寸模式及各模式数值（倍率值 / 目标宽 / 目标高分别记忆，互不污染）、输出格式、输出质量。恢复值逐项校验：模型 id 不在清单、数值非法等 → 该项静默回退默认，其余项照常恢复
- **写入**（退出时）：窗口关闭时将当前 UI 状态一次性写入；写入前做与恢复相同的合法性检查，非法值不写入
- **降噪不持久化**（grilling 定案）：降噪档位是临时选择，不进设置文件；启动与每次切换模型一律回到默认档（支持降噪 →"自动"；不支持 →"无"并灰置，工单 23/24 语义）

**Key interfaces:**
- 设置读写封装为独立小模块（文本 ini 解析无需外部依赖），供主窗口初始化与关闭流程调用
- 键名风格对齐 waifu2x-caffe 的 `Last*` 惯例（如 `LastModel` / `LastScaleMode` / `LastScale` / `LastScaleWidth` / `LastScaleHeight` / `LastOutputExt` / `LastOutputQuality`），section 名 `Setting`
- 主窗口初始化顺序：加载设置 → 填充控件 → 触发模型切换逻辑（能力钳制照常生效）

**Acceptance criteria:**
- [x] 设置模型 B + 指定宽 1920 + PNG + 质量 80 → 退出 → 重启：四项全部恢复
- [x] 尺寸模式各数值独立记忆：倍率模式的倍率、宽模式的宽、高模式的高，恢复时跟随所记模式
- [x] 降噪在任何启动/切换场景下均为默认档（支持→自动；不支持→无灰置），不随退出时的选择变化
- [x] `setting.ini` 中模型 id 改为不存在值 → 该项回退默认模型，其余正常恢复，无崩溃
- [x] `setting.ini` 删除/清空/截断 → 等同首次运行，无崩溃
- [x] 退出后 `setting.ini` 存在且为人可读的 ini 文本
- [x] 只读目录下运行：功能正常，仅不持久化，无报错弹窗

**Out of scope:**
- 窗口大小/位置的记忆（用户明确排除）
- 上次输入路径的记忆（用户明确排除）
- 降噪档持久化（用户明确排除——临时选择语义）
- CLI 参数启动时不保存设置的例外规则（waifu2x-caffe 有此规则；本 GUI 暂无 CLI 参数，留待未来）
- 设置编辑 UI（手改 ini 即可）
