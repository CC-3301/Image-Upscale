## 维护者定案（2026-09-20 本轮 triage）

1. **默认档**：档位齐备（无/低/中/高）的模型 → 「自动」；档位不齐的模型 → **最高可用档**
   （`realcugan-pro` = 无/高 → 「高」）；不支持降噪的模型 → 固定「无」并灰置（工单 23 判据不变）。
2. **记忆**：所有支持降噪的模型都记忆档位，但**不按模型各记各的**：
   - 档位齐备的模型（`waifu2x_upconv_7_art` / `waifu2x_cunet` / `waifu2x_upconv_7_photo` /
     `realcugan-se` / `realesr-general-x4v3`）**共用一份全局记忆**：在一个模型上改成「中」，
     切到另一个齐备档位的模型也是「中」。
   - 档位不齐、没有规范 0/1/2/3 档位的模型（当前只有 `realcugan-pro`）**各自独立记忆**。
3. **恢复时校验**：记忆档位不在当前模型的可用集合内 → 回退到该模型的默认档
   （例：全局记忆 = 低，切到只有 无/高 的 pro → 落「高」）。
4. **引擎不动**：`--denoise` 语义与 AUTO 估计器都不改（本次只是 GUI 的默认值与持久化）。

## 方案要点

- `SettingsStore` 新增：
  - `LastDenoise`（`auto` / `none` / `low` / `mid` / `high`，默认 `auto`）—— 全局共用槽。
  - `LastDenoise_<modelId>`（如 `LastDenoise_realcugan-pro`）—— 仅档位不齐的模型各写一个键，
    保存时按已加载模型清单遍历生成，非法值静默回退默认（沿用现有逐项校验语义）。
- `OnModelChanged`：按「齐备 → 全局槽 / 不齐 → 独立槽」取记忆值 → 校验档位存在 → 否则默认档。
  这样 `realcugan-pro` 首次运行落到「高」。
- 选档写回：`DenoiseBox.SelectionChanged` 时把当前档写进对应的记忆槽（内存态），退出时随
  现有 `OnClosing` 一次性落盘。**注意重入**：`OnModelChanged` 内部设置 `SelectedIndex` 会触发
  同一事件，必须用抑制标志包住，否则加载时默认值会覆盖记忆值。
