## 报告（维护者 2026-09-15 迭代需求 1）

新的记忆设置：记住上次关闭时的窗口大小和位置。

## 方案要点

- 扩展 `setting.ini`（工单 14 机制）：`LastWindowLeft/Top/Width/Height/Maximized`（`Last*` 键名惯例一致）
- 退出时写入：正常态写当前 Left/Top/Width/Height；最大化态写 `RestoreBounds`（最大化坐标不是恢复坐标）+ Maximized=1
- 启动时恢复：先设尺寸，再设位置；最大化则恢复尺寸后置 `WindowState=Maximized`
- 边界校验：与虚拟屏幕（`SystemParameters.VirtualScreen*`）无交集时放弃该值（显示器拔掉/分辨率变更防丢窗口），位置回退居中
- 与工单 14 的静默回退语义一致：值非法/缺失逐项回退，不崩溃

## Acceptance criteria

- [x] 拖动并调整窗口 → 关闭 → 重启：位置与大小恢复
- [x] 最大化状态关闭 → 重启：以最大化打开；还原后回到关闭前的正常位置尺寸
- [x] ini 中写入屏外坐标（如 -99999）→ 启动无异常，窗口出现在可见区域
- [x] 删除 ini → 默认尺寸位置启动
