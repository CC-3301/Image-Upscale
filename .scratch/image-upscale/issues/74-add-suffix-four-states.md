# 74: 添加后缀四态

**What to build:** 把「添加扩展名」开关换成「添加后缀」四态下拉，用来决定 `-(模型名)-nN-<倍率|尺寸>` 这段后缀落在**输出文件夹名**还是**产物文件名**上；引擎对应新增 `--suffix`，旧 `--no-rename` 保留为同义写法。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

| 状态 | 文件夹输入 | 单文件输入 |
|---|---|---|
| 开（两者，默认） | 产物进 `A-(m)-n2-2.0x/`，文件名 `1.png`；AUTO 逐文件档位不同时文件名补 `-n1/-n2` | `A-(m)-n2-2.0x.png` |
| 开（文件夹） | 产物进 `A-(m)-n2-2.0x/`，文件名永远干净 | `A.png`（覆盖源文件） |
| 开（文件） | 产物落源目录，文件名带整段 `1-(m)-n2-2.0x.png` | `A-(m)-n2-2.0x.png` |
| 关 | 产物落源目录 `1.png` | `A.png`（覆盖源文件） |

- [ ] 四态 × {文件夹输入, 单文件输入} 的产物目录与产物名与上表逐格一致
- [ ] AUTO 逐文件档位不同的文件夹批：两者 → 文件名补 `-n1/-n2`；文件夹 → 文件名干净、目录名写 `-nX`
- [ ] `--suffix both|folder|file|none` 可用；`--no-rename` 等价于 `none`，既有用法行为不变
- [ ] `LastAddSuffix` 旧值迁移：`1` → 开（两者）、`0` → 关；缺键或非法值回退开（两者）
- [ ] GUI 下拉标签为「添加后缀」，四个选项为 开（两者）/ 开（文件夹）/ 开（文件）/ 关
- [ ] 「文件处理」栏三个下拉在 780px 最窄窗口下不换行
- [ ] 任何输入状态下该下拉都不灰置
- [ ] 单文件 + 开（文件夹）且产物覆盖源文件时，输出日志最末尾追加一句覆盖警告
