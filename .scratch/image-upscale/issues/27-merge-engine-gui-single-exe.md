## 实施方案

- **引擎**：`main.cpp` 拆分——核心逻辑（清单解析、参数解析、文件循环、编码）移入 `engine_core.cpp`，导出 C API：
  `int iu_run(int argc, const wchar_t* const* argv, iu_line_cb out_cb, iu_line_cb err_cb, void* user)`
  全部 `fprintf(stdout/stderr)` 输出点改经回调（UTF-8 行，字节流与现行行协议完全一致）；
  `main.cpp` 变薄壳 exe（回调 = printf 到控制台 + `SetConsoleOutputCP`），**仅作测试缝保留，不再分发**
- **CMake**：新增 `iu_engine` SHARED 目标（ncnn/webp 静态链入）；`image-upscale` exe 目标链接 `iu_engine`，仅薄壳
- **GUI**：`EngineClient.Run` 改 P/Invoke `iu_run`（`wchar_t**` 参数免引号转义；回调 UTF-8 → 托管字符串）；行协议解析逻辑不变；`--models-dir` 由 GUI 显式传入（定位职责单一化，lessons §1.4）
- **打包**：分发布局 = `ImageUpscale.exe + models/ + 文档`（engine/ 消失）；`iu_engine.dll` 随发布以 Content 进单文件包（`IncludeNativeLibrariesForSelfExtract` 已开启，运行时自动解压至 `%TEMP%\.net`），打包脚本加守卫：包根出现散装 iu_engine.dll 即报错
- **架构记录**：ADR-0002 记录 DLL 化决策（取代 ADR-0001 中"独立引擎 exe 进程"的交付形态）；spec 用户故事 19/20/27（CLI）标记为已取代
- **测试**：pytest 缝（`IU_ENGINE` 指向 exe）不动；新增 ctypes 直调 `iu_engine.dll` 的冒烟测试锁住 P/Invoke 面
