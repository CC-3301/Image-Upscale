## 现状

`gui/MainWindow.xaml.cs` 里「这次输入是不是一个文件」这条判断写了三遍：

- 发参前判断是否追加 `--no-rename`（`File.Exists(input) && !_addSuffix`）
- `UpdateAddSuffixState` 的灰置跟随（决定下拉是否可点、是否强制显示「开」）

三处语义一致但各自成文：以后输入面变化（例如支持新的输入形态、或把"文件夹"判定改严），
必须同步改三处，漏一处就是静默不一致。

## 方案要点

- 在 `MainWindow` 上抽一个私有 helper（如 `bool IsFileInput()` / `bool IsValidInput()`），三处调用它。
- 保持判定口径与 `UpdateAddSuffixState` 一致（文件夹/空/无效路径 → 非文件输入）。
