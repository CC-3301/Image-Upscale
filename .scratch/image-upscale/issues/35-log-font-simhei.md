# 35: 处理日志字体统一用黑体（SimHei）

## 报告（维护者 2026-09-15 v0.2.2 验证反馈）

日志用的字体（Consolas）不满意；字体统一用黑体——维护者明确：就是 Word 里那个"黑体"（SimHei），别无其他。

## 方案

- `LogBox` FontFamily 由 `Consolas` 改为 `SimHei`；字号维持 12
- 中文 Windows 自带 SimHei（C:\Windows\Fonts\simhei.ttf 已确认存在）；非中文系统缺失时 WPF 回退系统默认字体，不影响使用
- 日志不再追求等宽（路径行对齐让位于中西文观感统一）

## Acceptance criteria

- [ ] 日志区中文与西文均以黑体渲染，与界面其余文字风格统一
- 二轮定稿（2026-09-15）：SimHei 12 仍不合意；最终改为 LogBox 删除 FontFamily 直接继承全局默认（与其余 UI 同源，中文=微软雅黑），字号 12→14
