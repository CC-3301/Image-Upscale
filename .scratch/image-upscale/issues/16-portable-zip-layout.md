1. GUI csproj 加 `<SatelliteResourceLanguages>zh-Hans</SatelliteResourceLanguages>` → 只产出中文资源目录（US25"全程只有中文"）
2. GUI 改 single-file 自包含发布（运行时收进 exe；WPF 需 `IncludeNativeLibrariesForSelfExtract=true`），根目录 DLL 即消失
3. 引擎 exe 收进子目录（如 `engine/`）；`MainWindow.LocateEngine` 已是候选路径列表机制，追加 dist 布局候选即可
4. 目标根目录形态：`ImageUpscaleGui.exe` + `models/` + `engine/`（+ zh-Hans 资源目录，若 single-file 后仍外置）
