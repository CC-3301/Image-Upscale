# 15: 带透明通道的大图处理崩溃（退出码 -1073741819 / 0xC0000005）

**Parent:** .scratch/image-upscale/spec.md

**Category:** bug

**Status:** ready-for-agent

> *This was generated by AI during triage.*

## 报告（2026-09-14 人工测试，原始描述）

"同时设置输出 PNG 和输出品质为 100 以下会报错"。附截图：日志显示 `mode=ratio`、输入 906x653 PNG、退出码 **-1073741819**（= 0xC0000005 访问违例，进程崩溃），GUI 弹"失败（退出码 -1073741819）"。

## Triage 重定性（报告者截图提供后）

格式与质量参数均与崩溃无关（GUI 对 PNG 根本不发送 `-q`）。真实触发条件是 **带 alpha 通道的输入图**（该截图为 RGBA PNG）——原始描述是误归因。

## 复现矩阵（已实证，重建后的 bld 引擎）

| 输入 | 输出格式 | 结果 |
|---|---|---|
| RGB 906x653（任意内容） | png | ✅ 正常 |
| **RGBA 906x653** | **png / webp** | ❌ **0xC0000005** |
| RGBA 906x653 | jpg | ✅ 正常（flatten 白底路径，不走合并块） |
| RGBA 64x48 | png | ✅ "正常"（见根源——侥幸） |

## 根源：use-after-free（`engine/src/main.cpp` alpha 合并块）

```cpp
if (has_alpha)
{
    ...
    std::vector<unsigned char> merged(outimage.w * outimage.h * 4); // 块作用域
    ...
    outimage = ncnn::Mat(outimage.w, outimage.h, (void*)merged.data(), (size_t)4, 4); // 非拥有视图
}   // ← merged 析构，outimage.data() 悬垂
// 编码阶段读 outimage.data() → use-after-free
```

尺寸依赖性的解释：小图合并缓冲（~48KB）释放后堆页仍映射，读旧值"碰巧不崩"；≥0.5MB 的分配走 VirtualAlloc，free 即去提交 → 编码读必崩。工单 04 的测试夹具全是小图，所以全绿。

## 分诊建议

推荐 `ready-for-agent`：

- 修复：把 `merged` 提升到与 `alpha_src` 同级（循环体顶部声明，块内 resize），或将 outimage 改为拥有数据的 `create` + memcpy。一处改动
- 回归测试：RGBA 大图（输出 ≥ 1MB，如 512x512）× 三种输出格式，断言退出码与产物 RGBA 通道正确（工单 04 测试补大图用例）
- 附带小改进：GUI 退出码映射表把 0xC0000005 类异常码翻译为"引擎异常崩溃"而非裸数值（`MainWindow.xaml.cs` 的 exitCode switch）

## Comments

### Agent Brief（2026-09-14 推进 ready-for-agent）

**Category:** bug
**Summary:** 修复 alpha 合并缓冲的悬垂指针：带透明通道的大图在 PNG/WebP 输出时崩溃（0xC0000005）

**Current behavior:**
带 alpha 的输入走"RGB 超分 + alpha 同步放大 + 合并"路径时，合并缓冲的生存期止于所在代码块，而输出图像仅是对它的非拥有视图；编码阶段读取已释放内存。小图（缓冲几十 KB）释放后堆页仍映射而侥幸不崩，大图（缓冲 ≥0.5MB，释放即去提交）必崩，表现为退出码 -1073741819。

**Desired behavior:**
合并缓冲的生存期覆盖"合并 → 编码 → 写盘"全过程；任意尺寸的 alpha 输入在三种输出格式下都正常产出（PNG/WebP 保 alpha，JPG 合白底），退出码 0。

**Key interfaces:**
- 引擎单文件处理循环中的 alpha 合并逻辑：缓冲生存期是唯一改动点，合并算法与输出格式分支不变
- GUI 退出码映射：0xC0000005 类异常退出码应显示为"引擎异常崩溃"而非裸数值

**Acceptance criteria:**
- [ ] pytest 新增大图 alpha 用例：RGBA ≥512x512（产物 ≥1MB）× png/webp/jpg，断言退出码 0、产物存在、PNG/WebP 产物含 alpha 通道且与输入 alpha 语义一致
- [ ] 报告者的实际崩溃图（906x653 RGBA 截图）复测通过
- [ ] GUI 收到崩溃退出码时弹窗文案为"引擎异常崩溃"（含原始码）
- [ ] tests 全量绿

**Out of scope:**
- alpha 分离推理算法本身的重写
- 工单 10 的灰度修复（已在工作区，另行提交）
