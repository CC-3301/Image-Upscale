# 19: 窗口缩放时 UI 不自适应，超出范围的元素被裁剪隐藏

**Parent:** .scratch/image-upscale/spec.md

**Category:** enhancement

**Status:** ready-for-agent

> *This was generated by AI during triage.*

## 报告（2026-09-14 人工测试）

UI 不会随窗口变化：拖动窗口改变宽高时，不在窗口范围内的元素直接隐藏（被裁剪）。

## Triage 验证记录（代码确认）

`gui/MainWindow.xaml`：各功能行是横向 `StackPanel`（模型/尺寸模式/降噪与输出/开始行）——窗口变窄时溢出部分被裁剪且不可达；窗口无 `MinWidth`/`MinHeight` 约束，也无 `ScrollViewer` 兜底。

## 分诊建议

推荐 `ready-for-agent`（与工单 12 对齐、18 日志可调同批做布局重构）：

- 设 `MinWidth`/`MinHeight`（按最窄可用布局估算）
- 易溢出行改 `WrapPanel` 或 Grid 多列自适应；整体套 `ScrollViewer` 兜底
- 日志行用 `Height="*"` 吃掉剩余空间

验收：窗口从 640px 拉到 1600px，所有控件可达、无永久性隐藏。
