## 分诊建议

- **依赖工单 23**：默认"自动"只对支持降噪的模型生效；不支持降噪的模型（digital-art-4x 等）灰置并固定"无"，否则默认值本身就会触发参数错误

## Comments

### Agent Brief（2026-09-14 推进 ready-for-agent）

**Category:** enhancement
**Summary:** 支持降噪的模型默认档位为"自动"，不支持降噪的模型固定"无"

**Current behavior:**
每次切换模型，降噪一律重置为"无"，用户处理有伪影的扫描图时容易忘记开降噪。

**Desired behavior:**
切到支持降噪的模型时默认选中"自动"；切到不支持降噪的模型时（依工单 23）控件禁用并固定"无"。切换模型不再产生非法组合。

**Key interfaces:**
- 与工单 23 的判据复用同一"支持降噪"概念
- 降噪档位是临时选择、不进入设置持久化（工单 14 grilling 定案）：任何模型切换与启动场景都直接落到本工单定义的默认档

**Acceptance criteria:**
- [x] 切到支持降噪的模型 → 默认"自动"
- [x] 切到不支持降噪的模型 → 灰置 + "无"（不产生错误退出）
- [x] A（支持）→ B（支持）→ A 的切换序列行为稳定（始终"自动"）
- [x] 重启后启动时档位同样为"自动"（降噪不持久化）
- [x] 依赖的工单 23 判据已落地（若 23 未完成，本工单不得先行合并）

**Out of scope:**
- 每模型档位记忆与持久化（工单 14）
- 引擎 AUTO 估计器行为
